# estudio rupit — web

Static React site (Vite + TypeScript) with TinaCMS for content editing, hosted on GitHub Pages.

- Site: https://mariasuevos.github.io/estudio-rupit/
- Editor: https://mariasuevos.github.io/estudio-rupit/admin/

## Quick start

```bash
npm install
cp .env.example .env
npm run dev          # site: http://localhost:5173 · editor: http://localhost:5173/admin/index.html
```
